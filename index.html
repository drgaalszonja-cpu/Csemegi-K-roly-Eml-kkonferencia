GitHub Pages feltöltés – lépésről lépésre
  1. Menj a github.com oldalra és hozz létre ingyenes fiókot
  2. Kattints a New repository gombra
  3. Adj nevet: pl. szavazas
  4. Állítsd Public-ra, majd Create
  5. Kattints uploading an existing file linkre
  6. Húzd be a letöltött szavazas.html fájlt
  7. Nevezd át index.html-re feltöltés előtt (vagy utána a GitHub-on)
  8. Settings → Pages → Branch: main → Save
  9. ~1 perc múlva elérhető: felhasználónév.github.io/szavazas
